# Codespaces-Demo

Ausschließlich für synthetische Demo- und Testdaten; keine produktiven Daten oder Zugangsdaten verwenden.
Das Repository ist öffentlich; der automatische Demo-Start erfordert Eigentümer- oder Schreibzugriff.
Der automatische Start prüft das Original-Repository und den Eigentümer beziehungsweise eingeladene Collaborators mit Schreibzugriff.
Port 3000 bleibt privat und ist nur über den authentifizierten Codespaces-Proxy erreichbar.

Auf GitHub unter **Code → Codespaces** einen Codespace erstellen und den privaten Port 3000 öffnen.
Die isolierten Demo-Zugangsdaten zeigt der Startprozess im Terminal; sie gehören nicht in GitHub-Texte.
Nach Servercodeänderungen den Container neu erstellen. Demo und produktiver Serverbetrieb verwenden getrennte Daten und Schlüssel.
