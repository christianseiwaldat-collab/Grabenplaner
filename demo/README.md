# Grabenplaner Musterkits und Demodaten

Dieser Bereich enthaelt ausschliesslich fiktive Unternehmen und Testdaten. Er kann oeffentlich verwendet werden; echte Personal-, Planungs- oder Gesundheitsdaten gehoeren nicht in diese Dateien.

## Branding-Kits

- [Fokus & Licht Fotohandel](branding-kits/fokus-und-licht-branding-kit.zip) - neutrales gruen-gelbes Musterkit fuer den Fotohandel
- [Berg & Ball Sporthandel](branding-kits/berg-und-ball-branding-kit.zip) - fiktives Sporthandels-Kit fuer die Codespaces-Demo

Die ZIP-Dateien koennen in Grabenplaner unter **Einstellungen > Branding** direkt importiert werden.

## Sporthandel-Demo

Die [Sporthandel-Demodaten](sporthandel/demo-profile.json) bilden sechs Filialen mit teilweise drei Abteilungen ab. Enthalten sind 31 Verkaufsmitarbeitende sowie je eine zusaetzliche Person fuer Administration und Personalleitung. Beim Erstellen eines frischen GitHub Codespaces wird dieses Profil automatisch eingerichtet.
